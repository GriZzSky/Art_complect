# Как запустить ART-COMPL

## Что загружать по FTP

В корне проекта есть три понятные папки для ежедневной загрузки:

- `ftp_product_catalog_xml` - сюда загружается XML каталога товаров
- `ftp_price_offers_xml` - сюда загружается XML цен и остатков
- `ftp_product_images` - сюда загружаются фотографии товаров

Для фото правило такое: имя файла должно начинаться с `external_id` товара без дефисов.

## Запуск через Docker

```powershell
cd C:\ART_COMPL\ART_COMPL-BACKEND
docker-compose up -d --build
```

После запуска:

- сайт: `http://127.0.0.1:8001`
- каталог: `http://127.0.0.1:8001/catalog.html`
- API docs: `http://127.0.0.1:8001/docs`

## Ручная синхронизация каталога

Если новые XML уже загружены в FTP-папки, выполните:

```powershell
cd C:\ART_COMPL\ART_COMPL-BACKEND
.\sync_catalog_from_docker.ps1
```

Команда возьмёт:

- самый свежий XML из `ftp_product_catalog_xml`
- самый свежий XML из `ftp_price_offers_xml`
- фотографии из `ftp_product_images`

Обработанные XML будут перемещены во внутренние архивы backend:

- `ART_COMPL-BACKEND\data\processed_feeds\product_catalog_xml`
- `ART_COMPL-BACKEND\data\processed_feeds\price_offers_xml`

## Структура backend

- `app/catalog` - всё, что относится к каталогу товаров
- `app/integrations` - FTP и другие внешние интеграции
- `app/api` - HTTP-эндпоинты
- `app/core` - конфигурация и база данных
- `app/utils` - служебные утилиты

## Запуск на сервере (VPS + Docker + Traefik + Let's Encrypt)

1. Пропишите DNS A-записи для `art-komplekt.shop` и `www.art-komplekt.shop` на IP сервера.
2. Скопируйте файл `deploy/.env.prod.example` в `deploy/.env.prod` и укажите email для Let's Encrypt.
3. На сервере выполните:

```bash
chmod 600 deploy/traefik/acme.json
docker compose --env-file deploy/.env.prod -f docker-compose.prod.yml up -d
```

4. Проверка:

- сайт: `https://art-komplekt.shop/`
- API docs: `https://art-komplekt.shop/docs`

Примечание: SEO-файлы `robots.txt` и `sitemap.xml` находятся в папке `FRONT` и раздаются через backend.

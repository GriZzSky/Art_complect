# АРТ-КОМПЛЕКТ - Сайт-каталог мебельной фурнитуры

## Описание проекта

Многостраничный сайт для компании "АРТ-КОМПЛЕКТ" - поставщика мебельной фурнитуры и комплектующих.

## Структура сайта

Сайт включает следующие страницы:

1. **index.html** - Главная страница
   - Слайдер с главным баннером
   - Блок "Почему выбирают нас" с карточками преимуществ
   - CTA-секция с призывом к действию

2. **catalog.html** - Каталог товаров
   - Боковое меню с фильтрами по категориям
   - Сетка товаров с карточками
   - Кнопки "В корзину" и "Подробно"

3. **promo.html** - Акции и специальные предложения
   - Баннеры с текущими акциями
   - Карточки акционных категорий

4. **about.html** - О компании
   - Информация о преимуществах компании
   - Раздел "Технологии комфорта"
   - Достижения (2+ года на рынке, 2000+ клиентов)
   - Официальные представители (партнеры)

5. **contact.html** - Контакты
   - Карточки с контактной информацией
   - Интерактивная карта
   - Режим работы

6. **cart.html** - Корзина покупок
   - Список добавленных товаров
   - Управление количеством товаров
   - Итоговая сумма заказа

7. **404.html** - Страница ошибки 404
   - Сообщение об ошибке
   - Предложения альтернативных страниц
   - Кнопка возврата на главную

## Особенности дизайна

### Цветовая схема:

- **Темно-синий (#12142B)** - основной цвет для footer, заголовков, акцентов
- **Оранжевый (#D59004)** - акцентный цвет для кнопок, иконок, CTA
- **Черный (#000000)** - шапка сайта
- **Белый** - фон, текст на темных элементах
- **Серый (#666, #888, #ccc)** - вторичный текст

### Основные компоненты:

- Sticky header с навигацией
- Адаптивная сетка для карточек товаров и услуг
- Кнопки с hover-эффектами
- Footer с контактной информацией
- Иконки (используются emoji, можно заменить на Font Awesome)

## Как запустить

1. Откройте файл `index.html` в браузере
2. Навигация между страницами работает через обычные ссылки
3. Для локального сервера можно использовать:
   - Python: `python -m http.server 8000`
   - Node.js: `npx http-server`
   - VS Code: расширение "Live Server"

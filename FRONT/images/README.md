# Папка для изображений

Поместите сюда изображения для сайта:

## Необходимые изображения:

1. **hero-bg.jpg** - Фоновое изображение для главного баннера
2. **product-\*.jpg** - Изображения товаров для каталога
3. **promo-\*.jpg** - Изображения для акций
4. **interior.jpg** - Фото интерьера для страницы "О компании"
5. **logo.png** - Логотип компании (опционально)

## Рекомендуемые размеры:

- Hero banner: 1920x500px
- Товары: 400x400px
- Акции: 600x300px
- Интерьер: 800x600px
